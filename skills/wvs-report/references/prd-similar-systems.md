# 유사 시스템 조사 가이드 (요청 5항 대응)

요청 5항: "분석한 자료 외에 정부 과제 조회 및 참여 가능한 과제 도출 등의 유사한 시스템을 보다 상세 조사하여 해당 기능들을 준용하며,
누락되거나 필수적으로 필요한 세부 기능은 (3항 오픈소스 +) 상용/오픈소스 프로그램을 최대한 참고하여 작성."

## 1. 해석 규칙
1. **유사 시스템 = 목표 시스템과 같은 일을 하는 통합형 제품.** 먼저 목표 시스템의 성격(예: 프로덕션 AI 운영 플랫폼, 문서 파싱 서비스, R&D 과제 탐색 서비스)을 한 줄로 정의하고 그 범주의 제품을 찾는다.
2. 요청문에 예시로 든 도메인(예: "정부 과제 조회 및 참여 가능한 과제 도출")이 목표 시스템 범주와 **같으면** 그 도메인 제품을 직접 조사하고,
   **다르면** 1.1 표에 "요청 예시 도메인 → 이 제품 문맥의 해석"을 명시한 뒤 목표 범주 제품을 조사한다(사용자 요구 대응표에도 기록). 해석을 숨기지 않는다.
3. 최소 12종(상용·OSS 혼합), 기능군별 매트릭스(●/◐/○), "대부분 제품이 비워 둔 기능", 공통 기능 필수도(필수/권장/선택) 판정 → 필수·권장은 X 도메인 FR 로 보강.

## 2. 공통 기능군 체크리스트 (통합형 플랫폼에서 반복 확인되는 것 — 조사로 확정)
워크스페이스·홈·검색 · 지식/메모리(RAG) · 승인함(HITL) · 샌드박스 실행 · 알림(Slack·메일·웹훅) · 템플릿·마켓 · 사용량/비용 리포트 ·
감사 로그 · 역할·권한 · SSO/SCIM · API·SDK · 가져오기/내보내기 · 다국어·접근성 · 온보딩 투어 · 도움말·지원 번들

## 3. 도메인 예시 — 정부 R&D·지원사업 과제 탐색 시스템 (요청 예시가 목표 범주일 때)
조사 후보(공식 URL·API 제공 여부·이용 조건은 조사로 실측, 확인 못 하면 [미확인]):
| 이름 | 성격 | 확인할 기능 |
|---|---|---|
| NTIS 국가과학기술지식정보서비스 | 국가 R&D 과제·성과·사업공고 통합 | 사업공고 검색·과제 이력·연구자 정보·Open API |
| IRIS 범부처통합연구지원시스템 | R&D 공고·신청·협약·평가 | 공고 알림·신청서 작성·평가 단계 |
| 기업마당(bizinfo) | 중소기업 지원사업 공고 | 분야·지역·대상 필터, 공고 API |
| K-Startup | 창업 지원사업 | 사업 공고·모집 일정 |
| SMTECH 중소기업기술개발사업 | 중기부 R&D | 공고·접수 |
| 공공데이터포털(data.go.kr) | 공고·기관 Open API | API 목록·인증키·호출 제한 |
| 상용 과제 매칭 서비스 | 공고 큐레이션·적합도 추천 | 자격 요건 파싱·적합도 점수·마감 알림·제안서 초안 |
핵심 기능 후보: 공고 수집(크롤/API) · 공고 정규화(자격·기간·예산·분야) · 기업/연구자 프로필 · 적합도(자격 충족·키워드·과거 수행) 점수와 근거 · 마감 알림 · 컨소시엄 파트너 추천 · 제안서 초안·체크리스트 · 진행 파이프라인(관심→준비→제출→결과).

## 4. 산출
- 4장 표·매트릭스·필수도 판정, 12.x X 도메인 FR(`FR-X-<기능>-NN`), 부록 B 출처(공식 URL), 16장 참고 OSS(owner/repo 실측).
