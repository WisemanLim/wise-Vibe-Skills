# PRD 장 구성 정본 (wvs-report prd)

이전 PRD(예: 「The map behind production AI systems」 기반 PRD, 21장 + 부록 A~F)의 장 구성을 일반화한 것이다.
`{ }` = 입력(분석 보고서·요구사항/개발방향 문서·첨부 이미지·참고 링크·요청문)에서 자동 추출, `[ ]` = 요청문·요구사항 문서에서 도출한 세부 요구(자동으로 장·FR·화면에 반영).
**출처·라이선스·참고 이미지는 항상 명시**하고, **형식(템플릿) 참고용 이전 문서는 출처에 넣지 않는다.**

## 표지
- 제품명 {Brand}(28pt) / 부제 "{원본 핵심 문구} — {N 레이어 · M 개념} 마이크로 에이전트 플랫폼 제품 요구사항 정의서 (PRD)"
- 태그라인: 원본 도식 구조 → 단위 에이전트 수 → 관리면·테넌트·UI/UX·설치 패키지·릴리스까지 정의했다는 요약
- 메타 줄: 작성일·버전 / 입력(인포그래픽 「{원제} ({원저작자})」 · 분석 보고서 「{보고서명}」 · 요구사항 문서 「{제목}」 · 첨부 이미지 N · 참고 링크 N — 있는 것만) /
  실측(GitHub REST API {날짜} 저장소 N개 · 사용자 스타 N개 · 사용자 저장소 N개 교차) / 규모(단위 에이전트 N + 플랫폼·공통 모듈 N · FR N개) / 표준·규격

## 1. 개요
- 1.1 이 문서가 다루는 것 — **사용자 요구 대응표**(# · 사용자 요구 원문 요약 · 이 문서의 대응 · 위치). 요청문의 번호 항목(1~6, *, **)을 한 행씩 빠짐없이.
- 1.2 입력 도식·이미지 — 구조 도식과 첨부 이미지 전부(출처: 원저작자 · 사용자 첨부 이미지, 분석 목적 인용). 이미지 입력이 없으면 그 사실만
- 1.3 핵심 결정 — 번호 목록 5~8개(세부 항목 1개 = 에이전트 1개, 프로토콜, 컨트롤/데이터 플레인 분리, 요청 경로, 폐루프, 콘솔 = 도식, 배포 규격)
- 1.4 문서 구성 — 장·제목·내용 표

## 2. 출처와 라이선스 표기
- 2.1 **입력 인벤토리**(`inputs_table()` — IN-ID · 유형 · 제목 · 경로/URL · 접근일 · 이용 범위·출처 표기) 2.2 실측 방법(gh api·레지스트리·arXiv)
- 2.3 표기 규칙(`[미확인]` 확인 못 함, `[도메인]` 업계 일반 가정, ★ 표기, SPDX, `*` 사용자 스타 표시)
- 2.4 인용·이미지 원칙(원본 도식 인용 범위, 그림 자체 작성, 상표, **형식 참고 문서는 출처에서 제외**)

## 3. 입력 분석·세부 항목 상세화 (`part03_inputs.py`)
- 3.1 입력별 전사·요약(`_INPUTS.md` — 도식: 레이어·카드·흐름·타일 원문 / 분석 보고서: 요구로 옮길 발견·도식 판정(일치/누락/과장 …)의 요구 변환 / 요구사항 문서: 목표·범위 / UI 시안: 화면·영역·컴포넌트 / 참고 사이트: 기능·IA·UI 패턴)
- 3.2 **요구사항 문서 정리(RQ)** — `req_table()`: RQ · 입력 · 구분 · 우선순위 · 원문 요약 · → FR·NFR·장
- 3.3 **단위 카탈로그**(단위 ID · 레이어 · 이름 · 원천 요소(원문·입력·RQ) · 책임; units.py 에는 A2A skill · 배포 이미지까지) — units.py 정본
- 3.4 입력 간 충돌·결정(우선순위: 요청문 > 요구사항 문서 > 분석 보고서·도식 > 이미지 > 참고 사이트)

## 품질 게이트(빌드 시 assert)
1. units.py 의 모든 단위가 FR 1개 이상, 모든 FR 의 단위 ID 가 units.py 에 존재
2. 도식 요소 목록(도식 전사)의 모든 요소가 1개 이상 단위·FR 로 추적
3. FR 전부가 화면 1개 이상에 매핑(ui_data SCREENS 의 PRD 추적 열) — 미커버 0
4. 참고 OSS 의 owner/repo 가 repos.tsv 실측에 존재(ERR 0) — 없으면 제외 또는 [미확인]
5. 기능·UI·비기능·제약 유형 RQ 전부가 FR(근거 열) 또는 req_map.tsv 로 이어짐 — 미매핑 0
6. `_INPUTS.md` 의 모든 입력 블록에 전사·요약이 있음
7. check_report.py: 빈 쪽 0, 금지 문자열(형식 참고 문서명) 0, 필수 FR·RQ ID 전부 등장
